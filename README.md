# Algemene Kennisquiz

Een quizwebsite met 20 algemene kennisvragen. Na het afronden ga je naar `bedankt.html`, waar je de uitslag via de knop naar janali3765@gmail.com kunt sturen.

De e-mailknop opent het standaard e-mailprogramma van de bezoeker. Voor automatische verzending zonder e-mailprogramma is een backend of e-maildienst nodig.
